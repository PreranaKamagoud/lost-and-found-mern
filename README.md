# Lost & Found

A full-stack web application developed using the MERN stack to help users report, browse, and manage lost and found items.

## Project Overview

The Lost & Found system provides a simple platform where users can report lost items and found items. Users can view available listings and manage their account. The application uses React.js for the frontend, Node.js and Express.js for the backend, and MongoDB for database management.

## Technologies Used

* MongoDB
* Express.js
* React.js
* Node.js
* JavaScript
* HTML5
* CSS3
* REST API
* Git & GitHub

## Main Features

* User registration and login
* Report lost items
* Report found items
* View lost and found item listings
* View individual item details
* User profile
* Admin dashboard
* Authentication and authorization
* MongoDB database integration

## How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/PreranaKamagoud/lost-and-found-mern.git
```

### 2. Open the project

```bash
cd lost-and-found-mern
```

### 3. Install backend dependencies

```bash
cd backend
npm install
```

### 4. Start the backend

```bash
npm start
```

### 5. Open another terminal and install frontend dependencies

```bash
cd frontend
npm install
```

### 6. Start the frontend

```bash
npm run dev
```

The application can then be opened using the local URL displayed by Vite.
